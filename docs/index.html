Ready to use it on your own idea?

Up and running in a few minutes, on your own machine.

You need: macOS, Linux, or Windows via WSL · Docker running (setup can install Colima for you) · Python 3.11+ · the AWS CLI (used locally, no AWS account needed) · git.

1

Clone and run setup

Run the command below once. It checks for Docker and Floci, offers to install what's missing (it asks first), creates its own Python environment, and connects itself to Claude Code and Cursor.

2

Open your chat app in that folder

Start Claude Code (or open the folder in Cursor) inside service-buddy and approve the server when asked.

3

Describe what you want

Try “Let people sign up and upload a profile photo.” No commands to memorize after that.

1

Run setup once

Claude Desktop still needs the local engine, so run the command below once in a terminal. It also adds Service Buddy to Claude Desktop's settings.

2

Restart Claude Desktop

Quit and reopen it, then describe what you want. Setting things up needs the assistant to run commands on your machine, which Claude Code and Cursor do out of the box, so they're the smoother path today.

3

Optional: the one-click bundle

A .mcpb bundle for macOS can be built with ./mcpb/build.sh (see mcpb/). A prebuilt one will be on the Releases page.

Run once, in a terminal
git clone https://github.com/ahmedkeewan/service-buddy.git && cd service-buddy && ./setup.sh

The README has the full setup guide, troubleshooting, and how to uninstall.

There's more once you're in

Chat is the front door, not the whole house. Three things worth knowing about once you're actually using it:

Watch it work, in a browser too

The conversation at the top of this page is a replay of a real run. Run make board and you get a live status page at localhost:7777 that updates in your browser as things get set up, side by side with the chat. You don't need it to get started.

Ask what it costs. Get a real answer.

Ask what something would cost on real AWS and it pulls live numbers from AWS's public price list instead of guessing. On 2026-09-25, 5 GB of file storage priced out at $0.11/month. 6 of the 13 capabilities get live prices; the rest show a clearly labelled estimate.

Setup that asks before installing anything

./setup.sh checks for Docker and Floci, offers to install whatever is missing (only with your yes), and connects Service Buddy to Claude Code, Cursor, and Claude Desktop in one pass. Safe to run again any time. macOS, Linux, and Windows via WSL.
