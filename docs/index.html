Get the bundle

Install it

Double-click the file, or drag it onto Claude Desktop, and click Install. No terminal, no editing config files by hand.

3

Start the local infra

Setup that asks before it touches anything

./setup.sh checks for Docker, offers to install it for you (with your yes, not without it), gets Floci running, and wires the config into Claude Desktop, Claude Code, and Cursor in one pass. Safe to run again any time. macOS, Linux, and Windows via WSL.
